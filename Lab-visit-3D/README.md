# ห้องเจาะเลือด 3 มิติ — ต่อข้อมูลจริงจาก HOSxP

ฉาก 3 มิติของห้องเจาะเลือด ที่ให้คนไข้ในฉากเดินตาม **คิวเจาะเลือดจริง** และ **การรับ Lab จริง**
ของวันนี้ในฐาน HOSxP (อ่านอย่างเดียว ไม่เขียนกลับ ไม่ดึงชื่อ/HN คนไข้)

## วิธีเปิดใช้

1. ดับเบิลคลิก `start.bat` (ใช้ Python ถ้ามี ไม่มีก็ใช้ Windows PowerShell ที่ติดมากับเครื่อง)
2. เบราว์เซอร์จะเปิด <http://localhost:8804/index.html>
3. วาง **Session ID** ที่ขอจาก HOSxP (เมนู BMS Session) ในหน้าต่างที่ขึ้นมา

> **ห้ามเปิด index.html ด้วยการดับเบิลคลิกไฟล์** (`file://`) — tunnel ของ HOSxP
> ปฏิเสธคำขอที่ไม่มี origin และหน้าเว็บจะต่อฐานไม่ได้ ต้องเปิดผ่าน `start.bat` เท่านั้น
> (`serve.py` / `serve.ps1` ทำหน้าที่เสิร์ฟไฟล์ + ส่งต่อคำขอไป `*.hosxp.net` พร้อมใส่ CORS/User-Agent ให้)

เปิด `http://localhost:8804/index.html?demo=1` = โหมดจำลองล้วน (ไม่ถามหา session)
ใส่ session ใน URL ได้ด้วย: `?bms-session-id=xxxxx`

## ข้อมูลจริงถูกแปลงเป็นอะไรในฉาก

| ในฐาน HOSxP | ในฉาก 3 มิติ |
|---|---|
| แถวใหม่ใน `lab_blood_queue` (วันนี้) | คนไข้เดินเข้ามา กดตู้บัตรคิว แล้วไปนั่งรอ |
| `lab_blood_queue_ref` | เลขบนป้ายคิวเหนือหัวคนไข้ และบนจอเรียกคิว |
| `lab_blood_queue_type` (ประเภทคิว) | เดินเอง / รถนั่ง / รถนอน (ตั้งทับเองได้ในหน้าตั้งค่า) |
| `lab_head.lab_receive = 'Y'` ของ visit เดียวกัน | เรียกเข้าโต๊ะ เจาะเลือด แล้วเดินไปรอหน้าห้องตรวจ |
| `lab_blood_queue_complete = 'Y'` หรือ `call_status` / `call_datetime` | เหมือนกัน (ถ้าโรงพยาบาลบันทึกช่องนี้) |
| `call_slot_number` | เลือกโต๊ะตามช่องที่เรียก (ถ้ามีค่า) |

**ทำไมถึงยึด "การรับ Lab" เป็นหลัก** — `lab_blood_queue` ที่ใช้งานจริง (ตรวจกับ ppbh_hosxp
18/11/2569) ปล่อยช่อง `lab_blood_queue_complete` / `call_status` / `call_*datetime` เป็น NULL
ทั้งตาราง จึงดูจากตารางคิวอย่างเดียวไม่ได้ว่าใครเจาะไปแล้ว ต้องดู `lab_head` ของ vn เดียวกัน
(ปิดได้ในหน้าตั้งค่า ถ้าโรงพยาบาลของคุณบันทึกสถานะคิวครบ)

## สิ่งที่ควรรู้

- **บัตรคิวใบเดียวอาจมีหลายแถว** (คนไข้หลาย visit ในวันเดียวได้ ref เดียวกัน) — รวมเป็นคิวเดียวแล้ว
- **ที่นั่งในฉากมี 36 ที่ + จุดรถนั่ง/รถนอน 3 จุด** ถ้าคิวรอมากกว่านั้น ส่วนเกินจะไม่ปรากฏตัวในฉาก
  แต่ยังนับรวมในตัวเลขบนจอ (ขึ้นว่า "+N ไม่ได้แสดงในฉาก")
- **ตัวเลขบนการ์ดขวา** ในโหมดข้อมูลจริง = คิวรอจริงแยกประเภท / จำนวนใบที่ห้องแล็บรับแล้ว / เวลารอนานสุด
- ดึงข้อมูลใหม่ทุก 30 วินาที (ปรับได้ 15 วิ – 2 นาที ในหน้าตั้งค่า) และเริ่มนับใหม่เองเมื่อข้ามวัน
- คนไข้ที่เจาะเสร็จไปแล้วก่อนเปิดจอ จะไม่ถูกสร้างย้อนหลังในฉาก (นับแต่ในตัวเลขสรุป)
- ส่ง SQL แบบ **SELECT อย่างเดียว** ผ่าน `/api/sql` ของ BMS Session และไม่ดึงชื่อหรือ HN คนไข้

## ไฟล์ในโฟลเดอร์

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | ทั้งฉาก 3 มิติ + ชั้นเชื่อมต่อ HOSxP (ไฟล์เดียวจบ) |
| `serve.py` / `serve.ps1` | เซิร์ฟเวอร์ในเครื่อง + proxy ไป `*.hosxp.net` (เลือกอัตโนมัติจาก `start.bat`) |
| `start.bat` | ปุ่มเริ่มใช้งาน (พอร์ต 8804 แก้ได้ที่บรรทัด `set PORT=`) |
| `lib/three.module.js` | three.js |
| `assets/` | พื้น ผนัง ฉากหลัง |
