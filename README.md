# BMS 3D Home — หน้าเลือกแอปแสดงผล 3 มิติ

หน้าแรกสำหรับเลือกเปิดแอป 3 มิติของโรงพยาบาล เปิดทิ้งไว้ที่เครื่องในห้องทำงานหรือจอติดผนังก็ได้
ตัวหน้านี้ไม่ต่อฐานข้อมูลเลย เป็นแค่หน้ารวมลิงก์ + ตรวจว่าแอปปลายทางเปิดอยู่ไหม

| แอป | พอร์ต¹ | ไฟล์ | คืออะไร |
|---|---|---|---|
| คนไข้ผู้ป่วยนอก Realtime 3D | 8803 | `patient-journey-3d/live.html` | แผนที่ 3 มิติทั้งแผนก OPD เห็นว่าคนไข้อยู่จุดไหน รอนานเท่าไร |
| ห้องเจาะเลือด 3 มิติ | 8804 | `Lab-visit-3D/index.html` | ห้องเจาะเลือด คนไข้ในฉากเดินตามคิวจริงและการรับ Lab จริง |
| คิวห้องตรวจแพทย์ 3 มิติ | – | `doctor-queue-3d/index.html` | ห้องตรวจแพทย์ เห็นคนรอซักประวัติ รอพบแพทย์ และคนในห้องตรวจ |
| ห้องฉุกเฉิน 3 มิติ | – | `er-triage-3d/index.html` | คนไข้ที่อยู่ใน ER ตอนนี้ (er_regist) นอนเตียงตามสีคัดกรอง พร้อมเวลาใน ER และเวลารอเกินเป้า |

## ที่อยู่ของไฟล์

โฟลเดอร์ของแอปทุกตัววางอยู่ **ข้างในโฟลเดอร์นี้** เพื่อให้ย้าย/คัดลอกไปเครื่องอื่นได้ทีเดียวจบ

```
BMS-3D-Home\
├─ index.html · start.bat · serve.py · serve.ps1 · Enable-LAN.bat · assets\   ← หน้า home (พอร์ต 8805)
├─ patient-journey-3d\   ← แอปคนไข้ OPD 3 มิติ (พอร์ต 8803) มี start.bat ของตัวเอง
├─ Lab-visit-3D\         ← แอปห้องเจาะเลือด 3 มิติ (พอร์ต 8804) มี start.bat ของตัวเอง
├─ doctor-queue-3d\      ← แอปคิวห้องตรวจแพทย์ 3 มิติ (เปิดจาก start.bat ตัวนี้เท่านั้น)
└─ er-triage-3d\         ← แอปห้องฉุกเฉิน 3 มิติ (เปิดจาก start.bat ตัวนี้เท่านั้น)
```

`start.bat` ของโฟลเดอร์นี้เสิร์ฟทุกส่วนจากที่เดียว ลิงก์ในหน้า home จึงเป็นพาธบนพอร์ตเดียวกัน
(เปลี่ยนพอร์ตที่ `set PORT=` ใน `start.bat` แล้วลิงก์เปลี่ยนตามเอง) · **ทุกแอปอยู่ใน repo นี้ repo เดียว**
(รวมเข้ามาเมื่อ 26/11/2569 พร้อมประวัติ commit เดิมของแต่ละแอป) — clone ครั้งเดียวได้ครบทั้งชุด

## วิธีเปิดใช้

**ดับเบิลคลิก `start.bat` ไฟล์เดียว** — เปิดทั้งหน้า home และแอปทุกตัวบนพอร์ตเดียวกัน (8805)

| ที่อยู่ | คืออะไร |
|---|---|
| <http://localhost:8805/index.html> | หน้าเลือกแอป |
| <http://localhost:8805/patient-journey-3d/live.html> | คนไข้ OPD 3 มิติ |
| <http://localhost:8805/Lab-visit-3D/index.html> | ห้องเจาะเลือด 3 มิติ |
| <http://localhost:8805/doctor-queue-3d/index.html> | คิวห้องตรวจแพทย์ 3 มิติ |
| <http://localhost:8805/er-triage-3d/index.html> | ห้องฉุกเฉิน 3 มิติ |
| `/proxy?url=…` | ทางผ่านไป HOSxP ที่แอปทุกตัวใช้ (tunnel ไม่ตอบ CORS) |

ในหน้า home **คลิกตรงไหนก็ได้ในกรอบของการ์ด** เพื่อเปิดแอปนั้น (ทั้งการ์ดเป็นลิงก์เดียว)
ถ้าอยากดูด้วยข้อมูลจำลอง เติม `?demo=1` ท้ายที่อยู่ของแอป

### ใส่ BMS Session ที่หน้า home ครั้งเดียว

ช่อง **BMS Session ID** บนหน้า home รับ session ที่ขอจาก HOSxP (เมนู BMS Session) แล้วกด **เชื่อมต่อ**
— หน้าเว็บจะตรวจกับ hosxp.net ให้ทันทีและบอกว่าเป็นโรงพยาบาลอะไร ถ้า session หมดอายุจะเห็นตั้งแต่หน้านี้
เมื่อคลิกเปิดแอป session จะถูกส่งไปให้แอป **ต่อ HOSxP เองอัตโนมัติ** ไม่ต้องวางซ้ำอีก

- ส่ง session มาทาง **URL ของหน้า home** ได้ด้วย เหมาะกับการทำ shortcut ไว้ที่จอติดผนัง

  ```
  http://<เครื่องที่เปิด start.bat>:8805/index.html?bms-session-id=XXXXXXXX-XXXX-XXXX-XXXX-XXXXXXXXXXXX
  ```

  หน้าเว็บจะรับไปใช้แล้ว **ลบออกจากแถบที่อยู่ให้เอง** (ไม่ค้างอยู่ในประวัติการเปิด) จากนั้นคลิกการ์ดไหนแอปก็ต่อให้เลย
- ค่าที่ใส่ถูกจำไว้ในเบราว์เซอร์ของเครื่องนั้น (`bms3d.sid`) กด **ล้าง** เพื่อเอาออก (ล้างของทุกแอปให้ด้วย)
- ส่งให้แอปสองทาง: แนบไปกับลิงก์ (`?bms-session-id=…` แอปจะลบออกจากแถบที่อยู่ให้เอง)
  และเขียนลงที่เก็บของแต่ละแอปเมื่ออยู่เครื่อง/พอร์ตเดียวกัน
- ข้ามช่องนี้ได้ ถ้าอยากไปวาง session ในแอปทีละตัวแบบเดิม

ใช้ Python ถ้าเครื่องมี ไม่มีก็ใช้ Windows PowerShell ที่ติดมากับเครื่อง (`serve.ps1`)
เซิร์ฟเวอร์ตัวนี้มี **แคช `/api/sql` ร่วมกัน 15 วินาที** ด้วย เปิดหลายจอพร้อมกันฐานข้อมูลจึงเห็นภาระประมาณจอเดียว
(ปิดด้วย `BMS_3D_CACHE_SEC=0` · ดูสถิติที่ `/cache-stats`)

> ¹ แอปคนไข้ OPD และห้องเจาะเลือดยังมี `start.bat` ของตัวเองอยู่ (พอร์ต 8803 / 8804) ถ้าอยากเปิดแยกแค่ตัวเดียว
> ส่วนคิวห้องตรวจแพทย์ไม่มีของตัวเอง เปิดจาก `start.bat` ตัวนี้อย่างเดียว
> แต่ปกติใช้ `start.bat` ตัวนี้ตัวเดียวก็ครบทุกแอปแล้ว

> หน้านี้เปิดแบบดับเบิลคลิกไฟล์ (`file://`) ก็พอใช้ได้ แต่การตรวจสถานะ "เปิดอยู่ / ยังไม่ได้เปิด"
> จะไม่ทำงาน ควรเปิดผ่าน `start.bat` เหมือนแอปอื่น

เปลี่ยนพอร์ตได้ที่บรรทัด `set PORT=` ใน `start.bat`

## ให้เครื่องอื่นในวงเปิดหน้านี้ได้

รัน `Enable-LAN.bat` หนึ่งครั้งที่เครื่องที่เปิด `start.bat` (ขอสิทธิ์แอดมิน)
— เปิดไฟร์วอลล์พอร์ต 8805 และจอง URL ให้ PowerShell ฟังได้โดยไม่ต้องเป็นแอดมินทุกครั้ง
แล้วเครื่องอื่นเปิด `http://<ไอพีเครื่องนั้น>:8805/index.html`

## แอปอยู่คนละเครื่องกับหน้านี้

ในหน้าเว็บมีช่อง **"ชื่อเครื่องหรือไอพีที่เปิดแอป"** พิมพ์ชื่อเครื่องหรือไอพีของเครื่องที่รันแอปจริง
(เช่น `192.168.1.50` หรือชื่อเครื่องในวง) แล้วการ์ดทั้งหมดจะชี้ไปเครื่องนั้น
ค่าที่พิมพ์ถูกจำไว้ในเบราว์เซอร์เครื่องนั้น ๆ
กด **"ใช้เครื่องนี้"** เพื่อกลับไปใช้เครื่องที่เปิดหน้านี้อยู่

## เพิ่มแอปที่ 3

รูปปกวางไว้ที่ `assets/` ขนาดสัดส่วน 8:5 (เช่น 800×500)
